# Documentation

Choose the guide for what you want to do:

| I want to… | Start here |
| --- | --- |
| Install or run Rove on Windows, macOS, or Linux | [Setup](setup.md) |
| Find code or run developer checks | [Development](development.md) |

Use `rove.py setup`, `rove.py check`, and `rove.py terminal` from the project root. Prefix them with `py` on Windows or `python3` on macOS/Linux. The setup guide lists prerequisites.

Older local research folders may also contain `docs/archive/`. Those notes describe earlier revisions; use the guides above for current instructions.
